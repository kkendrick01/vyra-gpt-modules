Neurons (Knowledge Units)

Discrete units of Brandon's teachings stored in brandon_content

🧠 What is a Neuron?

Each neuron represents a single, atomic piece of Brandon's knowledge. It could be a story he tells, a principle he believes, a technique he uses, or a question he asks. Neurons are extracted from transcripts, articles, and courses using AI — preserving Brandon's exact words, not paraphrased summaries.

Synapses (Connections)

Weighted connections between neurons that learn over time

🔗 What is a Synapse?

A synapse is a weighted connection between two neurons. The weight (0.01 to 0.99) indicates how strongly the neurons are connected. Higher weights mean the connection is more likely to fire during spreading activation — when one neuron activates, its strongly-connected partners activate too.

Synapse Weights

Weak
0.1 - 0.3
Medium
0.4 - 0.6
Strong
0.7 - 0.99

How Synapses are Created

🏷️ Tag-Based (weight: 0.5)

Neurons with shared tags are automatically connected. If two neurons are both tagged "identity", they get a synapse with initial weight 0.5. 

// Example tags:
"identity", "regulation", "sports",
"business", "relationships"
📍 Location-Based (weight: 0.6)

Neurons in the same OneOS location are connected with a slightly stronger initial weight of 0.6. 

// Example locations:
"CORE.WHO", "INNER.BELIEFS",
"OUTER.HEALTH", "META.TRACKING"

Hebbian Learning

"Neurons that fire together, wire together"

🧠 The Learning Mechanism

Every time neurons are retrieved together in a conversation, the synapses between them strengthen. Over time, the system learns which combinations of teachings work well together. Unused synapses gradually decay, preventing the network from becoming overly connected.

Strengthening Formula

When Neurons Fire Together
new_weight = weight + 0.1 × (1 - weight)
  • Weights increase with each co-firing
  • Maximum weight is capped at 0.99 (prevents saturation)
  • Delta decreases as weight approaches max (realistic learning curve)

Decay Formula

Unused Synapses (30+ days)
new_weight = MAX(0.01, weight - 0.02)

Synapses that haven't fired in 30+ days lose 0.02 weight, but never drop below 0.01. This prevents the network from becoming over-connected while preserving all learned connections.

Spreading Activation

When one neuron fires, connected neurons activate too

⚡ How It Works

When you ask a question, we first find direct semantic matches (neurons whose content matches your query). Then, activation spreads through strong synapses to retrieve connected neurons. This mimics how real brains work — thinking of one concept naturally activates related concepts.

Spreading Activation Visualization

Retrieval Algorithm

1

Direct Semantic Search 60% of results

Find neurons whose content semantically matches the user's query using vector similarity.

score = semantic × 0.50 + frequency × 0.20 + recency × 0.15 + success × 0.15
cosine similarity fire count 7-day half-life success rate
2

Spreading Activation 40% of results

From the top direct matches, follow strong synapses (weight ≥ 0.55) to find connected neurons.

SELECT connected neurons WHERE
  (neuron_a_id IN (top_neurons) OR neuron_b_id IN (top_neurons))
  AND weight >= 0.55
ORDER BY weight DESC, co_fire_count DESC
LIMIT 10
3

Combine & Format

Merge direct and spread neurons, deduplicate, and format for the prompt.

activation: direct activation: spread synapse weight

Retrieval Process

How neurons are selected for each conversation

// Main retrieval function
async function getRelevantBrandonNeurons(db, env, context, limit = 5) {
  // 1. Generate embedding for user's query
  const queryEmbedding = await generateEmbedding(context.currentMessage, env);

  // 2. Score all neurons (semantic + usage patterns)
  const scoredNeurons = neurons.map(neuron => {
    const semantic = cosineSimilarity(queryEmbedding, neuron.embedding);
    const frequency = neuron.global_fire_count / maxFires;
    const recency = Math.pow(0.5, daysSince / 7);
    const success = neuron.global_success_rate;

    return {
      ...neuron,
      score: semantic * 0.50 + frequency * 0.20 + recency * 0.15 + success * 0.15
    };
  });

  // 3. Get top direct matches (60% of limit)
  const directMatches = scoredNeurons.slice(0, Math.ceil(limit * 0.6));

  // 4. Spread activation through strong synapses
  const spreadNeurons = await spreadActivation(db, directMatches.map(n => n.id), 0.55);

  // 5. Combine, dedupe, return
  return [...directMatches, ...spreadNeurons].slice(0, limit);
}
